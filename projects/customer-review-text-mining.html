DATA MINING · MSc PROJECT 11

Customer Review Text Mining & Sentiment Analysis

Analysing language in 23,486 clothing e-commerce review records using R, sentiment dictionaries and topic modelling.

View R code ↗Read technical README ↗

Context

For my MSc coursework, I analysed a dataset of 23,486 customer reviews from a women's clothing e-commerce store. The aim was to identify recurring product concerns and explore the relationship between customer star ratings and written feedback.

Methods

  • Reviewed the dataset structure, cleaned review text, tokenised words and removed stopwords.
  • Measured word frequencies and visualised recurring product terms.
  • Applied Bing and AFINN sentiment lexicons and the NRC emotion lexicon.
  • Used Latent Dirichlet Allocation (LDA) with four topics to explore themes.
  • Compared lexicon scores by customer star rating.

Findings from the submitted report

The recorded analysis contains 102,311 positive and 25,621 negative Bing word matches. Frequent terms included dress, love, size and fit. Topic interpretations included sizing and fit, comfort and materials, appearance and general satisfaction. These figures count matched words, not positively or negatively classified people or reviews.

Code and reproducibility

The academic report includes R code and analysis outputs, but the original standalone R script and dataset have not yet been recovered. The public repository therefore includes a clearly labelled report-based recreation with fictional example reviews. Its code can run on a compatible dataset with the expected columns; the original numerical findings have not been independently reproduced in this environment.

Research limitations
Dictionary-based sentiment can miss negation, context and irony. A trend between text sentiment and star ratings does not by itself validate sentiment classification accuracy. The original reviews are not published pending licence verification.
