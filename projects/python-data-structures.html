PYTHON COURSEWORK · CASE STUDY 08

Python data structures & statistical functions

A practical Python assignment demonstrating file parsing, two-dimensional lists, dictionaries, numerical calculations and recursion without third-party packages.

Context

During my MSc Principles of Computing module (IS4S761), I implemented functions to read a column-based text format and work with multiple data structures.

What I built

  • Two file parsers that return a 2D list or a dictionary
  • Lookup and aggregation functions that support either data structure
  • Manual implementations of total, mean and median
  • A recursive maximum function and checks for missing or non-numeric values
  • Independent automated tests added for the portfolio

Outcome

Eight functions preserved from the original submission and reformatted for readability. Five portfolio unit tests pass against sample inputs. The functions use only Python's standard library.

Public portfolio note
This is foundational academic programming, not a production data-processing package. Instructor-provided exercise comments have been removed; the logic comes from my own submitted Python files.
