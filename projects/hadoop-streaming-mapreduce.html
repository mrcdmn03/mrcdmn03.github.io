BIG DATA ENGINEERING · MSc PROJECT 10

Hadoop Streaming & MapReduce

Two text-processing workflows built for a university Big Data Engineering assignment: word-frequency analysis and sentence-ending punctuation counting with Python, Hadoop Streaming and HDFS.

View Python source code ↗ Read technical README ↗

Context

For MS4S21 Big Data Engineering and its Applications, I used Hadoop Streaming to practise distributed text processing. I prepared Python mapper and reducer logic, checked Hadoop services, uploaded input texts to HDFS and inspected the job results.

Task 1 · Word-frequency analysis

Analysed Charles Dickens's A Christmas Carol. The mapper lowercases text, splits words and filters punctuation before emitting key-value pairs. The reducer sums frequencies per word. In the supplied source edition, the most frequent word was the (1,786 occurrences), followed by and (1,131).

Task 2 · Sentence-marker count

Analysed Herman Melville's Moby Dick by counting each period, exclamation mark and question mark. The original coursework's final Hadoop output reported 10,969 sentence-ending marks; I reproduced the same count locally. This is punctuation counting, not full linguistic sentence segmentation.

Reproducibility & quality checks

  • Four Python mapper/reducer scripts reconstructed from screenshots of my original coursework.
  • Automated local workflow that simulates Hadoop's shuffle/sort and produces tab-separated results.
  • Four passing unit tests using small sample texts; no third-party Python packages needed.
  • Hadoop execution wrapper with HDFS input and output commands for an existing cluster.
  • Source-edition SHA-256 hashes and verified output tables included for traceability.
Project provenance
The supplied coursework archive contains reports, screenshots and the original text files, but not the standalone original Python scripts. These have been reconstructed for the portfolio, preserving the documented algorithms. Local code and results were tested; Hadoop itself has not been rerun. The source ebooks are linked in the README rather than republished on GitHub.
