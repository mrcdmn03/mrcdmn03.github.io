BIG DATA ENGINEERING · MSc PROJECT 09

AWS Data Engineering & Telemetry Validation

A practical AWS coursework project connecting S3 storage, DynamoDB imports and data-quality checks, with EC2 networking and AMI exercises.

View code and documentation ↗Read technical README ↗

Context

For the MS4S21 Big Data Engineering and its Applications practical coursework, I implemented cloud data and infrastructure tasks for the fictional EcoStream Energy organisation. The work covered an energy telemetry dataset, database filtering and basic AWS compute/networking.

What I worked on

  • Configured Amazon S3 with blocked public access, versioning and SSE-S3 encryption.
  • Imported 100 facility telemetry records into DynamoDB from S3, using Facility ID as the partition key.
  • Validated five filtered DynamoDB Scan operations, including a rule detecting impossible downtime in leap-year 2024.
  • Created a VPC with one public and two private subnets; deployed a basic Apache site on Amazon Linux EC2.
  • Created a custom Ubuntu Amazon Machine Image with Node.js and launched a validation instance.

Results and validation

The original 100-record coursework dataset produced 11, 23, 18, 35 and 1 matching records across the five data-validation checks. These counts were independently checked against the supplied source data during portfolio preparation.

Runnable code

I also prepared a separate, reproducible Python demonstration that implements all five filter conditions against 40 fictional DynamoDB-format records. It produces CSV exports and includes five passing automated tests. An optional read-only boto3 Scan example is included, but has not been tested on a live AWS table.

Source and privacy
The coursework used AWS Console configuration and submitted guides. The Python reproducibility scripts were developed separately for this portfolio, not submitted as the original assignment. Original dataset records, AWS console images and account details are not published; public sample data is synthetic. The cloud environment is not represented as a currently running service.
