WORKFLOW AUTOMATION · CASE STUDY 05

AI-assisted video production workflow

Evidence-based review of real Claude Code subagent activity supporting video planning, editorial reviews, SEO and publishing preparation.

View technical case study ↗

Context

Explored the use of Claude Code subagents to separate footage review, editing plans, quality assurance, metadata, and YouTube publishing preparation into smaller AI-assisted tasks. The source of this case study is the user's local Claude Code project history, inspected without releasing session transcripts.

Verified activity records

A read-only review of the YouTube project history identified 19 subagent session log files and 27 Task/Agent tool-use entries. The observed agent-type names were general-purpose (24 entries), web-fetch (2), and head-of-production (1).

These counts measure different things. A log file is not a unique agent, and an agent task request is not proof that the operation completed successfully.

Recorded workflow areas

  • Footage ingest and editorial blueprint preparation.
  • Production oversight and quality-assurance review requests.
  • Trailer editing iterations and independent reviews.
  • YouTube SEO research and metadata preparation.
  • Private-upload preparation and Instagram trailer coordination.

Technical approach and next steps

The broader design considered 11 specialised roles, but the reviewed records do not verify that 11 distinct custom-agent definitions were deployed. The planned architecture uses role-specific task contracts, independent QA, explicit approval decisions and separation of publication permissions. Converting this workflow into a repeatable software system would require configuration files, tests and an auditable execution layer.

See the technical README for an architecture diagram, observed evidence and implementation limitations.

Evidence and privacy
This is a documented case study of observed task orchestration, not a claim of fully automated editing or successful uploads. Raw Claude transcripts, production assets and connected credentials have not been published.
