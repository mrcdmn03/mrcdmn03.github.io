APPLIED STATISTICS · MSc PROJECT 12

Statistical Modelling & Customer Segmentation

Three datasets, three business questions: car-value modelling, employee wellbeing factors and gym member motivation profiles.

View Python source ↗Technical README ↗

Project context

In my individual MSc Applied Statistics assessment, I worked through three practical exercises in SAS Studio. For the public portfolio, I developed a separate Python implementation to show how the same methods can be reproduced and tested.

Methods

  • Car value: Pearson correlation and multiple linear regression using age, salary, maintenance, comfort and advertising predictors.
  • Employee wellbeing: analysis of 14 survey dimensions using correlation matrices, standardised principal components and scree plots.
  • Gym member motivation: K-Means clustering of fitness, social, facilities and cost priorities, with three interpretable clusters.
  • Reproducible Python pipeline with automated checks and clearly labelled synthetic demonstration data.

Findings and interpretation

The original car-value model was statistically significant, but explained approximately 24% of the variation (R² ≈ 0.24). Advertising and comfort were associated with perceived value. The original wellbeing analysis did not find a convincing low-dimensional factor structure. Gym motivations varied across three descriptive clusters.

Research and reproducibility note
The university coursework was performed in SAS Studio. The GitHub Python scripts are an independently prepared portfolio adaptation, not the original SAS project. The uploaded university CSVs are not redistributed; demonstration data are fictional. Different extraction or clustering settings can change the results.
