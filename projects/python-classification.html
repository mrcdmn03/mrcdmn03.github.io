ACADEMIC PROJECT · CASE STUDY 03

Python machine-learning classification

Prepared a breast-cancer dataset and evaluated Logistic Regression and Random Forest classifiers using confusion matrices and ROC-AUC.

View source code and notebooks ↗

Context

Practise a complete supervised-learning workflow, from data exploration through model evaluation, on a classification dataset.

What I worked on

  • Cleaned and explored a breast-cancer dataset with pandas and NumPy.
  • Built Logistic Regression and Random Forest classifiers.
  • Used confusion matrices and ROC-AUC to assess model behaviour.
  • Compared classification approaches as part of academic work.

Outcome

Published the original 58-cell assessment notebook alongside a corrected, independently executed machine-learning pipeline. In the revised evaluation, Logistic Regression achieved 95.61% accuracy (ROC-AUC 0.9838), while Random Forest achieved 97.37% accuracy (ROC-AUC 0.9964) on a stratified hold-out test set. Both models were assessed for false negatives.

Public portfolio note
The original university notebook is preserved with outputs cleared. A separate, reproducible version addresses data leakage, duplicate records and -999 missing-value markers. Project code, modified coursework dataset, results, and execution instructions are available in the linked GitHub folder. This is an academic demonstration, not a medical diagnostic tool.
