# Mining Operations — Daily Production Report (Excel)

**Excel reporting · KPI analysis · Mining operations · Public portfolio demonstration**

This portfolio project illustrates the structure of a professional **daily mine production report** using a visually recognisable green-and-white reporting layout, Excel formulas, budget-to-actual comparison, pit-level production summaries and a one-page PDF dashboard.

## View or download

- [**Download the Excel workbook**](Mine_Production_Report_Public_Demo.xlsx) — formula-driven demonstration report, monthly trends, pit summary and equipment data.
- [**View the PDF dashboard**](Mine_Production_Dashboard_Public_Demo.pdf) — printable one-page management report derived from the same simulated overall metrics.

## What the report demonstrates

- Daily, **month-to-date (MTD)** and **year-to-date (YTD)** production reporting.
- Ore movement, waste movement and total production tonnage.
- Plan-versus-actual **variance percentages**.
- Pit-level quarterly production reconciliation.
- Monthly production trends, alongside separate equipment-availability indicators.
- Excel calculations using cross-sheet references, `SUM` and `IFERROR`.

| Worksheet | Purpose |

## Data provenance and confidentiality

**Every production figure and identifier in these public files is simulated, not an actual employer record.** The original workplace workbook and the PDF exported from it were **not** published because residual proprietary information could not be ruled out. The public Excel and PDF are independently reconstructed **portfolio examples**, with similar report concepts and visual cues. They should not be interpreted as authentic employer data, company performance, or a recovered original spreadsheet.

### Reproducibility and limits

The Excel file contains editable cells, formulas and illustrative tables. The PDF is a **static snapshot** of the synthetic reporting scenario. This is a limited, public-safe illustration rather than the much more extensive private production workbook. It does not contain Power BI or a live database connection.

## Professional context

The format reflects practical experience preparing and reviewing operational production reports, investigating source-data differences and presenting KPIs to technical and management stakeholders. The demonstration separates transferable analytical skills from private company records.
